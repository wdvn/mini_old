🤖 WebMCP Browser Extension

Available MCP Tools

  • get_current_url
    Get the current URL of the active tab
  • navigate
    Navigate to a URL
  • get_page_content
    Get page content as text or HTML
  • click
    Click an element by CSS selector
  • fill
    Fill a form field
  • screenshot
    Take a screenshot of the current page
  • evaluate
    Execute JavaScript in the page context
  • get_elements
    Get elements matching a CSS selector
  • list_tabs
    List all open tabs
  • switch_tab
    Switch to a tab by ID

Configuration

How to Use

  1. Install this extension in Chrome: chrome://extensions/
  2. Enable "Developer mode" and click "Load unpacked"
  3. Configure mini-agent to use MCP server at http://127.0.0.1:8765

Mini-agent MCP Config (~/.mini/mcp.json):

{
  "servers": {
    "browser": {
      "command": "node",
      "args": ["path/to/mcp-server.js"]
    }
  }
}
